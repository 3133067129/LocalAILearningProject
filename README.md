# 24周学习计划 → 40周修订版

> 为**安徽农业大学经济学本科毕业生**定制。
> **每天 1 小时**，每周学 **6 天**，周日休息或复习。
>
> **修订原因**：原计划把多个主题塞进一天（例：第三天「列表、元组、字典」），1 小时学不完。
> 本版改为**每天只学一个主题 + 一个小练习**，节奏更稳、每步都能真正掌握。

---

## 📋 计划总览

| 阶段 | 周数 | 核心目标 |
|:---|:---:|:---|
| **第一阶段：基础准备** | 第1-14周 | Python编程 + 数据处理 + 数学基础 |
| **第二阶段：从零手写神经网络** | 第15-22周 | 用NumPy从零实现神经网络，理解反向传播 |
| **第三阶段：深度学习框架** | 第23-29周 | PyTorch入门与实战 |
| **第四阶段：经典模型架构** | 第30-36周 | CNN、RNN/LSTM、Transformer |
| **第五阶段：股价预测项目** | 第37-40周 | 搭建LSTM股价预测模型 |

> 每周 6 天学习 + 周日休息/复习。每天**只学 1 个主题**，练透再进下一个。
